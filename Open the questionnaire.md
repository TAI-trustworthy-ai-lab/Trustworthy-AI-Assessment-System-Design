# Front-end webpage using guide (temporary because we just make an html)

## Prerequisites

- python

## 1. Download the file

Download the files
- questionnaire.html
- login.html
- questions.json

and put them in the same folder.

## 2. Open a localhost server and open the questionnaire.html

Use command or terminal to open the server

first use `cd` command go to the folder which you save the file and type

```sh
python -m http.server 8000
```

open http://localhost:8000/ on browser
and next open the questionnaire.html from the page

(you can decided the port number by youself)
